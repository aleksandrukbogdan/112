# Тренажёр оператора ДДС · Москва

Учебная система для операторов службы 112. Заказчик — Департамент ГОЧСиПБ города Москвы.

**Полная инструкция — [INSTRUKCIYA.md](INSTRUKCIYA.md):** что куда положить, как развернуть,
как подключить модели, как войти со своего компьютера, что делать при ошибках.

## Запуск за три команды

```bash
tar xzf t112-msk.tar.gz -C /data/t112 --strip-components=1 && cd /data/t112
make up            # всё: БД, приложение, голос, GigaAM;  make up-cpu — без GPU
make tunnel        # покажет команду для вашего ПК
```

На своём компьютере: `ssh -i ваш_ключ -N -L 8080:localhost:8080 root@адрес_сервера`,
затем http://localhost:8080. Вход: `admin/admin112`, `teacher/teacher112`, `trainee/trainee112`.

## Что внутри

| | |
|---|---|
| Контейнеры | t112-db (PostgreSQL 16), t112, t112-voice, t112-asr (GPU), t112-llm (по желанию) |
| Роли | администратор, преподаватель, обучающийся — с ограничениями по ТЗ |
| Классификатор | v0.46.24: 1283 позиции, теги Признак 1/2/3, условная маршрутизация СМП и полиции |
| Банк вызовов | 96 вызовов из билетов, 22 с эталонным адресом |
| Заявитель | локальная модель; скрывает точный адрес до уточняющего вопроса; без модели — на правилах |
| Генератор | черновики сценариев по классификатору, публикация только после утверждения преподавателем |
| Оценка | граф доказательств: 8 фактов, все правилами, у каждого ссылка на норму |
| Прогноз | внутри вызова (проверяется фактом) и до освоения навыков (BKT) |
| Аналитика | обучающийся, группа, тепловая карта с проваливанием до вызова, рекомендация = билет |
| Отчёты | формы 1/112 и 2/112 приказа МЧС № 192, PDF-отчёт занятия, сертификат, Excel |
| Режим ДДС | карточка от «оператора 112» с ошибкой, запись разговора, IP-телефон с бригадами, статусы по факту докладов |
| Речь | GigaAM v3 на GPU (основной), Vosk на CPU (запасной, автоматически), Piper — голос заявителя; всё офлайн |
| Служебное | мониторинг занятий в реальном времени, журнал аудита, резервная копия раз в сутки |
